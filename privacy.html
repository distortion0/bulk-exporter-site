Privacy Policy

Last updated: October 6, 2026

This Privacy Policy explains how Bulk Exporter for Descript (the “extension”) handles information when you use it. It also covers this website. “We”, “us” and “our” refer to the developer of the extension. The extension is an independent product and is not affiliated with Descript.

Summary

  • Your Descript API token is stored locally in your browser.
  • Transcripts are retrieved directly from Descript’s API and processed locally by the extension.
  • We do not collect your transcript content, and we do not currently operate a backend or database for the extension.
  • The extension does not currently use analytics or tracking.

What the extension does

Bulk Exporter for Descript is a Chrome extension for exporting transcripts from multiple Descript projects at once. You connect it with your own Descript API token, search and select the projects you want to export, choose a transcript format (TXT, Markdown, DOCX or SRT), and download the result as one organized ZIP file.

Your Descript API token

To use the extension, you provide your own Descript API token. The extension saves the token locally in your browser using Chrome’s chrome.storage.local extension storage, so you do not have to enter it each time.

The token is used only to authenticate the extension’s requests to Descript’s API. It is sent to Descript’s API as part of those requests. It is not sent to us.

You can remove your saved API token at any time through the extension’s Settings.

Communication with Descript’s API

The extension communicates directly with Descript’s API at https://descriptapi.com. Requests go from your browser to Descript’s API. They do not pass through servers operated by us.

The extension uses the API to load your projects and to retrieve the transcripts of the projects you choose to export.

Transcript processing and ZIP generation

Transcript data retrieved from Descript’s API is processed locally by the extension, in your browser. The extension converts the transcripts to the format you chose and generates the ZIP file locally on your device. The ZIP file is then downloaded to your device, where it remains under your control.

We do not collect, receive or store your transcript content.

Local storage

The extension uses chrome.storage.local, a storage area that Chrome provides to extensions, to keep information it needs on your device, such as your saved Descript API token. Data in chrome.storage.local is stored within your Chrome profile on your device. It is not sent to us.

Information we do not collect

  • Transcript content. We do not collect, receive or store the content of your transcripts.
  • Your API token. Your Descript API token is not sent to us.
  • Analytics or tracking data. The extension does not currently use analytics or tracking.
  • Server-side data. We do not currently operate a backend server or database for the extension, so the data it handles is not transmitted to or stored on systems operated by us.

Payments and licensing

The extension does not currently include payment or licensing functionality. If that changes, this policy will be updated to cover it.

Permissions

The extension currently uses the following Chrome permissions:

  • storage — to save your Descript API token locally using chrome.storage.local.
  • Host access to https://descriptapi.com/* — to send requests directly to Descript’s API.

Third-party service: Descript API

The extension relies on Descript’s API, a third-party service operated by Descript. When you use the extension, your browser sends requests to Descript’s API, including your API token, and Descript returns your project and transcript data.

Descript’s handling of that information is governed by Descript’s own terms and privacy policy, not by this policy. We do not control Descript’s services.

Removing your data

  • You can remove your saved API token at any time through the extension’s Settings.
  • Exported ZIP files stay on your device until you delete them.
  • Your API token is issued by Descript. To revoke or replace it, use the options Descript provides.

Data security

The extension is designed so that your API token and transcript data stay on your device, apart from the requests made directly to Descript’s API, which are sent over HTTPS.

No method of electronic storage or transmission is completely secure, and we cannot guarantee absolute security. Your saved API token is only as protected as your device and your Chrome profile: anyone with access to them may be able to access it. Treat your API token like a password, remove it through the extension’s Settings when you no longer need it, and revoke it with Descript if you believe it has been exposed.
